# TaxStatus

The tax applicability of the product: `taxable` (the product is taxed), `shipping` (only the shipping is taxed, the product itself is exempt) or `none` (neither is taxed).


## Values

| Name       | Value      |
| ---------- | ---------- |
| `TAXABLE`  | taxable    |
| `SHIPPING` | shipping   |
| `NONE`     | none       |
